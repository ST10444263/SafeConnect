# SafeConnect

SafeConnect is an Android safety application designed to help users
respond to emergencies, report incidents, manage emergency contacts,
and share safety information with the community.

## Features

- User registration and login
- Firebase Authentication
- Emergency SOS functionality
- Emergency contact management
- Incident reporting
- Community safety reports
- Live incident/responder status
- Location services
- Push notification support
- Language selection
- Profile and settings management
- Google and Facebook login interface
- Offline Firestore support

## Technologies Used

- Kotlin
- Android SDK
- Android Studio
- Firebase Authentication
- Firebase Firestore
- Firebase Cloud Messaging
- Google Play Services Location
- Retrofit
- Kotlin Coroutines
- AndroidX
- Material Components

## Requirements

- Android Studio
- Android SDK
- Android device or emulator
- Firebase project configured for the application
